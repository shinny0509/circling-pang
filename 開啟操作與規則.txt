Circling Pang v1.0　開啟、操作與規則說明

本文件以歸檔最後版 versions\circling-pang-v1.0.html 為準。
頁面名稱為 circle pang，頁尾保留開發時的 v1.5 SPIN ARCS；這是同一份最後版檔案。

============================================================
一、使用工具與執行環境
============================================================
- 製作形式：瀏覽器數位原型，單一 HTML 檔（HTML5 + CSS + 原生 JavaScript）。
- 繪圖：Canvas 2D，邏輯解析度 320 × 320，依視窗大小縮放顯示。
- 聲音：Web Audio API 即時合成擊球、旋球、得分及結束音效，沒有外部音檔。
- 第三方套件：無。遊戲不需要伺服器、連網、安裝或編譯。
- 執行環境：支援 Canvas 2D、JavaScript 與 Web Audio 的桌面瀏覽器。
  實際檢查若遇到相容性問題，可在 跨組檢查紀錄.txt 的回饋欄說明作業系統及瀏覽器版本。
  本次文件整理未重新進行瀏覽器試玩，不沿用其他作品的實測設備資料。
- 需要的硬體：電腦與實體鍵盤。不支援手機觸控操作。
- 開發與修改：任何支援 UTF-8 的文字編輯器皆可。本作以 AI 協作方式製作原型。

============================================================
二、開啟方式
============================================================
1. 下載並解壓縮專案，找到 versions\circling-pang-v1.0.html。
   若從 GitHub 下載，可在儲存庫選 Code → Download ZIP，解壓縮後找同一路徑。
2. 對 HTML 按右鍵 →「開啟方式」→ 選桌面瀏覽器，例如 Chrome 或 Edge。
   若 HTML 已關聯瀏覽器，也可直接雙擊。
3. 看到「circle pang」、圓形球場及「YOU VS CPU」，就代表遊戲頁面已載入。
4. 按 W 或「開始比賽」，即可與電腦開始遊玩。
5. 若按鍵沒反應，用滑鼠點一下遊戲頁面，讓瀏覽器取得焦點；若顯示暫停，按 W 恢復。
6. 聲音需在使用者操作後啟用。若沒有聲音，確認畫面顯示「音效：開」及系統音量未靜音。

若要修改：先另存副本，再用文字編輯器開啟 HTML，存檔後按 F5 重新整理。
重新整理會重置目前比賽與頁面記憶體中的事件紀錄；需要保留資料時請先匯出 JSON。

============================================================
三、操作
============================================================
- A：球拍沿圓周逆時針移動。
- D：球拍沿圓周順時針移動。
- W：標題畫面開始比賽、暫停時繼續、結算後重新開始。
- 接球：球與有效球拍接觸時自動觸發，不需要額外按擊球鍵。
- 暫停／繼續比賽：點畫面下方按鈕。
- 音效：點「音效：開／關」切換。
- P2：由電腦自動準備與移動，不需要第二位玩家。
- 切換分頁或視窗失焦時自動暫停；回到視窗後仍需按 W 或「繼續比賽」。

移動有慣性：按住同方向會逐漸加速，放開會減速至停止；按反方向先煞車，再反向加速。
旋球判定使用球拍實際運動方向，因此煞車途中按了反方向，不代表球拍已經反向移動。

============================================================
四、遊戲流程
============================================================
標題畫面 → 按 W → 發球預告 → 三分鐘比賽
→ 一方失誤、另一方得分 → 得分提示 → 下一球發球預告 → 繼續比賽
→ 時間歸零立即結算 → 按 W 重新開始

- 發球預告 0.5 秒，預告期間兩支球拍不能移動。
- 發球方位於場地下方，對手位於上方，兩支球拍速度歸零。
- 預告結束時，球從圓心向下射出，雙方同時開放移動。
- 第一球的預告不計入三分鐘；開賽後的得分提示與發球預告照常計時。
- 每次得分提示 0.3 秒，之後交替發球方並自動發下一球，不需要玩家手動發球。
- 最後十秒有倒數提示。歸零立即結束，不等待當前回合打完。

============================================================
五、規則
============================================================
目標：在三分鐘內取得比電腦更多的分數。分數相同為平手，不加時。
角色：P1 琥珀色球拍由玩家控制，P2 青綠色球拍由電腦控制。

1. 輪流接球
   - 只有當前接球方的實心球拍能擊球；球會穿過另一方的空心球拍。
   - 有效擊球後，接球資格交給對方。
   - 兩支球拍可以重疊與互相穿過，不會卡位或推擠。

2. 計分與失誤
   - 有效回球必須先回到場內，但不要求通過圓心。
   - 有效回球後，對手漏接使球出界，由最後擊球者加 1 分。
   - 擊球後未先回到場內就出界，算擊球者失誤，由對方加 1 分。
   - 發球後第一拍漏接，由發球方失分，對手加 1 分。
   - 得分後繼續比賽，沒有生命數或淘汰機制。

3. 旋球與球路
   - 球拍移動狀態會影響擊球後旋轉；保留部分來球旋轉，再疊加本次擊球影響，並設上限。
   - 球飛行時旋轉逐漸衰減，球路因此彎曲；相同狀態與輸入會得到相同球路。
   - 逆旋大弧：球拍實際運動與來球旋轉不同向，傾向較大幅度側送、較晚彎回。
     畫面提示 COUNTER / WIDE。
   - 順旋早彎：兩者同向，傾向較小側偏、較早彎回。畫面提示 WITH / EARLY。
   - 球拍接近靜止或來球幾乎無旋轉時，沿用一般回球。
   - 逆旋可能先抵消原旋轉；若幾乎抵消，側送角度也會縮小。不是每次都出現同一條大弧線。
   - 出球保持朝場內的分量，不採用先出界再彎回的規則。

4. 球速
   - 基礎球速隨整場時間由 92 增加至 184 px/s，得分後不重置成開場速度。
   - 擊球後依新旋轉強度給予 0～50% 球速加成；最強加成下最高為 276 px/s。
   - 加成保持到下一次有效回擊，不隨飛行中的旋轉衰減；回擊時重新計算，不累乘。
   - 得分與新發球清除加成；新發球使用當時的基礎球速。

5. 電腦對手
   - 每 160 毫秒觀察與預判一次球路，只輸出移動方向。
   - 使用與玩家相同的慣性、煞車和速度上限，仍可能漏接。

============================================================
六、畫面資訊（HUD）
============================================================
球場內：
- P1／P2 與數字：玩家及電腦分數。
- 03:00 倒數：剩餘比賽時間。
- NEXT P1／NEXT P2：下一位應接球的角色。
- 實心／空心拍：有／無當前接球資格。
- P1 SERVE／P2 SERVE：發球預告。
- P1 +1／P2 +1：本次得分者。
- WITH / EARLY、COUNTER / WIDE：本拍順旋早彎或逆旋大弧類型。
- FULL TIME 與 P1 WINS／P2 WINS／DRAW：比賽結束及勝負結果。

球場下方：
- NEXT / YOU、NEXT / CPU：輪到玩家或電腦接球。
- BALL N PX/S：目前球速；SPIN +N%：本拍旋球速度加成。
- 中文狀態列：開始、暫停、發球、得分原因與結算提示。

展開「原型觀測 · 本機試玩紀錄」：
- 顯示球速、旋轉、本拍球路、加成、雙方轉速、累積擊球、最長對打及遊戲時間。
- 「匯出本場事件 JSON」可下載 circle-pang-session.json，保存分數、參數及事件。
- 資料不自動上傳，重新整理頁面會清除；事件緩衝最多保留 4,000 筆。

============================================================
七、製作限制（1976 街機情境）
============================================================
- 單一遊戲畫面，不捲動球場：320 × 320。外圍說明頁可隨視窗大小排版。
- 球場 4 色：深黑 #101010、米白 #F2E8CF、琥珀 #F4B942、青綠 #65C8AE。
- 核心物件：兩支弧形球拍、一顆球。
- 玩家輸入：左右方向（A／D）與準備／重玩（W）；暫停、音效為頁面按鈕。
- 電子音效：Web Audio 即時合成。
- 完整循環：標題 → 遊玩 → 勝／敗／平手 → 重新開始。
本作使用現代瀏覽器模擬復古街機限制，沒有在真實 1976 年硬體上驗證。

版本補充：
- v0.1：加入電腦對手，已有基本旋球；頁尾原始編號 v1.1 CPU。
- v0.2：加入旋球強度加速獎勵；頁尾原始編號 v1.3 SPIN BOOST。
- v1.0：最後版，加入逆旋大弧／順旋早彎；頁尾原始編號 v1.5 SPIN ARCS。
較早版本不具備後續新增功能，請勿以最後版的全部功能要求檢查舊版。
