# Circling Pang｜Cycle 1 開發歷程歸檔

圓形場地中的 Pong 原型：玩家沿圓周移動弧形球拍，輪流回擊，利用慣性與旋球製造落點變化，在三分鐘內爭取較高分。

本資料夾保存三個 HTML 開發階段及完整對話文字，供遊玩、查閱設計決策與延續開發。作者已於 2026-10-24 確認上傳本次歸檔。

儲存庫：https://github.com/shinny0509/circling-pang

## 3. 操作與建置說明

完整的純文字說明見 [開啟操作與規則.txt](開啟操作與規則.txt)。

### 開啟遊戲

1. 下載並解壓縮歸檔 ZIP，或下載本儲存庫。
2. 進入 `versions`，使用桌面瀏覽器開啟想玩的 HTML；最後版本為 `circling-pang-v1.0.html`。
3. 按 W 或畫面的準備／開始按鈕，即可與電腦對手遊玩。

需要支援 HTML Canvas、JavaScript 的桌面瀏覽器與實體鍵盤。程式、樣式與電子音效均由檔案內程式提供，可離線執行，不需要 npm、編譯、伺服器或帳號。

實際使用的瀏覽器、版本及設備：**待作者補充**。手機觸控操作未列入本原型支援範圍。

### 操作方式

| 功能 | 操作 |
|---|---|
| P1 沿圓周移動 | A 逆時針／D 順時針 |
| 準備、重玩 | W 或畫面按鈕 |
| P2 | 電腦自動準備與移動 |
| 暫停、繼續、靜音 | 畫面按鈕；暫停時可按 W 恢復 |

持續按住方向鍵會加速，放開後減速，反方向輸入先煞車再反向加速。離開分頁或視窗失焦時會自動暫停。

### 遊戲規則與版本差異

雙方輪流接球，兩支球拍可以互相穿過。移動中的球拍影響擊球後旋轉。有效回球須先回到場內，對手漏接出界則得分；回球未先回到場內則由對手得分。系統自動發球，球速隨整場時間增加。每場三分鐘，到時立即結算，分數較高者獲勝，同分平手。

- **v0.1**：電腦接手 P2，保留基本旋球與慣性移動。
- **v0.2**：依擊球後旋轉強度提供 0～50% 球速加成，持續至對手回擊，再重新計算；得分與新發球清除加成。此階段亦包含先前的調慢速度設定。
- **v1.0**：保留旋球加速，新增逆旋大弧、順旋早彎。判定依碰撞瞬間球拍實際運動方向與來球旋轉方向，不只看按鍵。

### 修改與建置

用文字編輯器以 UTF-8 開啟 HTML，修改、儲存後重新整理瀏覽器即可。建議先複製新檔進行後續開發，保留這三個 Cycle 1 歸檔版本。
